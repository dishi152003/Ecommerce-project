# Admin Dashboard

## Access the Admin Panel

Navigate to: `http://localhost:5173/admin`

## Features

### ✅ Completed
- **Dashboard** - Overview with statistics, recent orders, and top products
- **Product Management** - View, search, and filter products
- **Responsive Sidebar** - Mobile-friendly navigation
- **Modern UI** - Beautiful gradient cards and animations

### 🚧 Coming Soon
- Orders Management
- Customer Management  
- Categories Management
- Analytics & Reports
- Settings & Configuration
